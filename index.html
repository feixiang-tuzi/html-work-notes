PS 抠图换背景

从解锁背景到导出成品的完整流程

一、解锁背景图层

在图层面板双击「背景」图层 → 点击「确定」，解锁为普通图层。

二、AI 自动抠主体

  1. 菜单栏：选择 > 选择主体（AI 自动识别主体）。
  2. 点击顶部工具栏的选择并遮住。
  3. 右侧面板调整：边缘检测（微调发丝边缘）、全局调整（平滑 / 羽化）。
  4. 右下角输出设置选「新建带有图层蒙版的图层」→ 确定。

三、处理发丝 / 毛绒边缘

  1. 左侧选「调整边缘画笔工具」（画笔带括号图标）。
  2. 在发丝与背景交界处反复涂抹，AI 会智能保留发丝。
  3. 右侧勾选净化颜色 → 输出到「新建带有图层蒙版的图层」→ 确定。

四、换背景

换成图片：把新背景图拖入 PS → 在图层面板拖到人物图层下方 → Ctrl+T 调整大小位置后回车。

换成纯色（证件照）：面板底部点「创建新填充或调整图层」→ 选「纯色」→ 拾色器选颜色 → 确定 → 拖到人物图层下方。

五、导出

  • 网络 / 朋友圈（JPG）：文件 > 导出 > 导出为… → 格式 JPG、品质 100%（最佳），勾选「转换为 sRGB」，元数据选「无」或「版权信息」。
  • 透明背景（PNG）：同样路径，格式 PNG，确保勾选「透明度」。
  • 打印（最高品质）：文件 > 存储为… → JPEG「最佳」(12) 或 TIFF（LZW），前提是分辨率达 300 像素 / 英寸。
  • 保留图层（PSD）：文件 > 存储为… → Photoshop (PSD)。
日常最常用：导出为… + JPG + 品质 100% + 勾选 sRGB，画质无损。
